# Code of Conduct

## The short version

Be respectful. This project attracts security researchers, journalists, and
investigators — treat each other as professionals.

## Not tolerated

- Harassment, discrimination, or personal attacks against contributors.
- Using the project's spaces (issues, PRs, discussions) to coordinate stalking,
  doxxing, or other harm against any individual.
- Sharing real case data, personal information, or leaked credentials in issues
  or pull requests.

## Scope

Applies to all project spaces and to public spaces when representing the project.

## Enforcement

Report unacceptable behavior by opening an issue or contacting the maintainers
privately. Maintainers may remove content, comments, and contributors that
violate this code.

This is a condensed adaptation of the [Contributor Covenant](https://www.contributor-covenant.org/).
